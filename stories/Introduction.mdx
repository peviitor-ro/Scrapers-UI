# Scrapers-UI Component Documentation

Welcome to the Scrapers-UI Storybook documentation! This interactive documentation showcases the components and patterns used throughout the project.

## Getting Started

To run Storybook locally:

```bash
npm install
npm run storybook
```

This will start Storybook on [http://localhost:6006](http://localhost:6006).

## What's Included

This Storybook includes:

- **Alert Component**: Notification and alert system
- **Company Card**: Company information display
- **Job Card**: Job listing display
- **Button Styles**: Various button variations
- **Form Elements**: Input and form components

## Project Structure

The Scrapers-UI project uses vanilla JavaScript, HTML, and CSS with no framework dependencies. Components are organized by functionality and reused across multiple scraper pages.

## Main Components

### 1. Alert System
Displays success, error, and info messages to users with automatic dismissal.

### 2. Company Cards
Shows company information including logo, name, and relevant links in a flip-card format.

### 3. Job Listings
Displays scraped job data with filtering and search capabilities.

### 4. Console Output
Shows real-time scraper execution logs and output.
